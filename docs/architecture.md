# Architecture notes

## Sensitive data

| Data | Purpose and storage | Recipients and processing location | Retention and deletion |
| --- | --- | --- | --- |
| Account-linked learning time zone | Assign a completion to a local calendar day. The learning module reads an optional browser request header and pins the IANA zone in `learning_sessions.state.TimeZoneId`. The current profile uses its request zone without persisting it. | Verbulio API and PostgreSQL on the private preview VPS, with access limited to authorized operators. VPS region remains to be confirmed before public release. The preview has no external data recipient for this field. | Retained with preview session records. Scheduled retention and account deletion are pending. An operator removing test data deletes the owner's session rows or destroys the isolated preview database. |
| Account-linked credited day and completion time | Count current and longest streaks. `learning_days` stores the owner, credited date, first accepted completion instant for the date and its IANA time zone. The profile returns counts to the owning account. | Same private preview application, PostgreSQL and authorized operators. Only the owning account receives computed counts. No external provider receives completion data in the preview. | Retained in the preview until operator cleanup. Delete the owner's credited-day rows as part of removal before deleting the account row, or destroy the isolated preview database. Account lifecycle and scheduled retention remain separate work. |
| Account-linked learning preference | Store the automatic advance choice for the owner in `accounts.auto_advance`. The default is off. | Verbulio API and PostgreSQL on the private preview VPS. Only the authenticated account and authorized operators can access the stored value. The preview has no external data recipient for this field. | Retained with the account and removed with its row. Scheduled retention and account deletion are pending. |
| Account email address | Registration and sign-in use `accounts.email` and `accounts.normalized_email`. The settings contact read returns the registered address only to its authenticated owner. | Verbulio API and PostgreSQL on the private preview VPS, with access limited to the owning account and authorized operators. Email delivery to an external provider is pending. | Retained with preview accounts and removed with their account rows. Scheduled retention and account deletion are pending. |
| Operator account export | On a verified request the operator can create a versioned JSON copy of the account's contact, placement, learning activity and preferences. Generated output is a private file outside the database. | Read from the authorized Verbulio PostgreSQL environment. The intended recipient is the verified owner through an approved private channel. Preview tests use isolated synthetic accounts and no external recipient. | Operators remove the temporary generated copy after processing. Formal export-file retention and delivery procedures are pending approval before handling public requests. |
| Verified account deletion journal | Prevent restored backups from reinstating accounts. `verified_account_deletions` stores the account UUID and verified request time in an independent PostgreSQL database. The password is used for verification and is never written to the journal. | Isolated PostgreSQL fixtures for this increment. Deployment operators maintain the independent journal before a shared environment enables deletion. Only authorized operators and the application deletion/replay process access this data. | Keep journal entries for at least as long as any application backup containing the account remains restorable. The final retention schedule and shared-environment journal provisioning are still pending. |
